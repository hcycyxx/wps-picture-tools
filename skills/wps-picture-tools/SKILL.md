# WPS 图片选择工具

只选择当前工作表的图片或单元格，用户右键转换并自行保存。不要恢复自动转换或后台另存发送版。先核对项目版本、启用加载项和用户授权范围。

- 嵌入方向识别 DISPIMG 公式，选择单元格和合并区域，不读取图片尺寸或要求取消隐藏。
- 浮动方向仅选择左上角目标为空的图片；目标有文字、数字、公式（含显示空白）、错误值均跳过；同一空目标多图全部跳过，不拆组合。
- 两个图片按钮只选择，数量在状态栏显示；不自动右键、不发快捷键、不写数据或保存。
- 每表分别操作，不承诺跨表一次转换。保留已有其他功能，尤其三个金额按钮。
- 构建、安装、用户验收分别记录。当前 1.5.0 的原用户已确认选区正确、有内容图片被排除；新电脑安装和 WPS 原生转换速度未验证。
- 旧自动转换存在大文件缓慢、隐藏行中断，菜单自动化亦失败；当前只选择的目标不应扩展为这些失败方案。

需要安装、构建或移植时读 [维护说明](references/implementation.md)。源码快照在 assets/addin-source，先检查实际项目是否更近。保留旧版，不改其他插件或宏安全设置，不上传客户资料。
