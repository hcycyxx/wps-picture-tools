# WPS 图片选择工具 v1.5.0

当前表中选择嵌入图片单元格，或选择目标为空的浮动图片，由用户右键转换。保留三个金额大写复制按钮。

下载 WpsPictureTools-Setup-v1.5.0.exe，先打开支持 VBA 的 Windows WPS 表格，再运行安装。更新会停用本工具旧版本，保留旧文件；停用按钮不删除文件。不修改宏安全设置。

已验证：用户实际按钮选区正确、有内容目标的图片已排除；现有五按钮加载项已安装。安装 EXE 已构建并作包内容只读校验，未另作新电脑安装验收。WPS 原生右键转换的尺寸与耗时由 WPS 决定。

附件包含安装 EXE、完整源码文档 ZIP、可安装 skill ZIP、XLAM 手动安装包和 SHA256SUMS.txt。
